# Workshop - Projeto Low-Code

Projeto desenvolvido durante o curso Be Digital Power Developer da Kodie com foco em soluções Low-Code, utilizando ferramentas de automação, inteligência artificial e serviços do Google para criar um fluxo de captação de dados e envio automático de e-mails.

## 📋 Sobre o Projeto

A aplicação foi construída utilizando a plataforma Builder.io por meio de prompts, com o objetivo de demonstrar como ferramentas Low-Code podem ser utilizadas para criar soluções funcionais de forma rápida.

O fluxo do projeto funciona da seguinte forma:

1. O usuário preenche um formulário criado no Google Forms.
2. As respostas são armazenadas automaticamente em uma planilha do Google Sheets.
3. Um script desenvolvido no Google Apps Script lê os dados da planilha.
4. O script envia e-mails personalizados automaticamente para os contatos cadastrados.

## ⚙️ Automação de E-mails

O Google Apps Script foi utilizado para automatizar o envio de e-mails com base nas informações armazenadas na planilha.

Funcionalidades implementadas:

- Leitura automática das respostas do formulário
- Validação básica de e-mails
- Personalização do assunto e conteúdo das mensagens
- Envio automático para os contatos cadastrados
- Resumo do processamento após a execução
